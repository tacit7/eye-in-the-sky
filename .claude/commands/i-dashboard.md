# Open Dashboard

Open the Eye in the Sky dashboard in your browser to view all active agents.

## Instructions

1. Ensure the MCP server is running
2. Open http://localhost:8080 in your browser
3. View all active agents and their current activities

## Example

```
Open http://localhost:8080 in your default browser to view the dashboard.

The dashboard shows:
- All active agents and their statuses
- Recent actions and activities
- Git commits tracked
- Session details and progress
```

## Usage

```
/i-dashboard
```
