# Eye in the Sky Help

Get help and documentation for Eye in the Sky MCP tools.

## Instructions

Use the `i-help` MCP tool to get comprehensive documentation for all available tools or a specific tool.

## Example

**All tools:**
```
Use the i-help MCP tool without parameters to get documentation for all tools.
```

**Specific tool:**
```
Use the i-help MCP tool with:
- tool: "i-register"
```

## Available Slash Commands

- `/i-start-session` - Register agent and start tracking
- `/i-end-session` - Complete session with summary
- `/i-sessions` - List all sessions with filtering options
- `/i-track` - Quick status update
- `/i-save` - Save session context for resumption
- `/i-note` - Add contextual note
- `/i-commits` - Log git commits
- `/i-dashboard` - Open web dashboard
- `/i-help` - Show this help

## Available MCP Tools

- `i-register` - Register new agent
- `i-register-claude-desktop` - Register Claude Desktop agent
- `i-status` - Update agent status
- `i-action` - Log agent activities
- `i-commits` - Track git commits
- `i-end` - Complete agent session
- `i-save-context` - Save session state
- `i-load-context` - Load session state
- `i-note` - Add session note
- `i-list-sessions` - List all sessions with filtering
- `i-window` - Get current window (macOS)
- `i-bring-front` - Bring window to front (macOS)
- `i-help` - Get tool documentation

## Usage

```
/i-help
```
