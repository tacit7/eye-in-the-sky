# Track Activity

Quick status update for current activity.

## Instructions

1. Use the `i-status` MCP tool to update your current status
2. Set status to: active, working, idle, completed, or failed
3. Optionally provide current_task description

## Example

```
Use the i-status MCP tool with:
- agent_id: your agent id
- status: "working"
- current_task: "{{task}}"
```

## Usage

```
/i-track Implementing JWT validation middleware
```

This updates your status to "working" with the specified task.
