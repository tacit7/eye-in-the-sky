# End Session

Complete your work session with a summary of what was accomplished.

## Instructions

1. Use the `i-end` MCP tool to complete your session
2. Provide a summary of work completed
3. Set final_status to "completed" or "failed"
4. Log any final commits if not already tracked

## Example

```
Use the i-end MCP tool with:
- agent_id: your agent id
- summary: "{{summary}}"
- final_status: "completed"

Before ending, ensure all commits are logged with i-commits.
```

## Usage

```
/i-end-session Successfully implemented user authentication with JWT tokens
```
